## Task

Perform a professional code review of the Collection Importer project. Run automated analysis tools, review code quality, and generate a comprehensive report saved to `/tmp/`.

## Reference Files

Project standards:
@CLAUDE.md

Tool configuration:
@pyproject.toml

Source code to review:
@collection_importer/

## Step 1: Generate Timestamp

Get current timestamp for the report filename:
!`date +%Y-%m-%d_%H-%M-%S`

## Step 2: Run Automated Analysis

### Static Analysis (ruff)
Run ruff linter and capture output:
!`ruff check collection_importer/ 2>&1 || true`

### Type Checking (mypy)
Run mypy type checker:
!`mypy collection_importer/ 2>&1 || true`

### Test Coverage (pytest)
Run tests with coverage report:
!`pytest --cov=collection_importer --cov-report=term-missing -q 2>&1 || true`

## Step 3: Manual Code Review

Review the codebase against CLAUDE.md standards:

1. **Type Hints**: Verify all public methods have complete type hints (Python 3.11+ style)
2. **Docstrings**: Check for Google-style docstrings on public methods
3. **Exception Handling**: Verify custom exceptions are used properly
4. **Code Architecture**: Assess separation of concerns and module organization
5. **Security**: Check for potential vulnerabilities (injection, XXE, sensitive data exposure)
6. **Test Coverage**: Evaluate test quality and edge case coverage
